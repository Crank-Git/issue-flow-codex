## Port defects found (not fixed)

1. `skills/issue-flow/SKILL.md:620-623` (verdict section) and FR-worker-dispatch-20. The rule is `timeout_ms` = `codex.waitMs`. The PM used other values. Main run (config 60000): four `wait_agent` calls with 10000 (18:24:00, 18:24:28 to 18:26:11), then 60000. Probe A (config 10000): `wait_agent` with 3600000 (18:34:23, 18:38:06) and 30000 (18:37:19). Both gpt-6.1-sol and gpt-6-luna did it. Expected: every call uses the configured value. Probe F, with 10000, did obey.
2. Same section, step 1 (`timed_out` true: run the A0 sweep, then wait again). In the main run, four timeouts (18:25:30, 18:25:42, 18:25:57, 18:26:11) got one sweep (18:25:55, between the second and third). Probe F obeyed on all 12. The rule works but not reliably. Expected: a sweep after each timeout.

Neither defect blocked a criterion. Both are in the PM prose, so a wording or a guard change belongs to a separate issue.
